# github-milestone

Lees agency/rules/github.md. Controleer status en scope, voer relevante tests uit, inspecteer diff op secrets en onbedoelde bestanden. Commit eigen taakbestanden met een duidelijke boodschap. Push zonder force naar de werkbranch en vergelijk remote SHA met HEAD. Meld blokkades direct. Lever commit- en bestandslinks op de werkelijk gepushte branch. Publiceer geen website naar productie.
